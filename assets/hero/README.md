# LichtArts hero asset map

These production WebP layers were composed from the transparent PNG elements supplied in `Website.zip`.

- `environment.webp` — mountains.png, mountains-with-architecture.png, architecture.png, clouds-1.png, floating-island.png
- `foliage-ribbons.webp` — tree-left.png, top-branches.png, hanging-leaves.png, brush-1.png, brush-4.png
- `hero-character.webp` — hero-character.png
- `desk-props.webp` — hero-desk.png, window.png, sketches.png, dove.png, lantern.png, ink-bottles.png, artpens.png
- `foreground.webp` — wood-foreground.png, leaves-blur.png, windy-leaves.png

The source artwork was optimized for the web and grouped by depth so the homepage can use lightweight multi-layer parallax instead of one flattened screenshot.
